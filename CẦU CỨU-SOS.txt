IF = NẾU 
bạn không vào được ME launcher thì bạn hãy làm theo văn bản này 
1. vào thư mục .\build\dist\ME Launcher trong thư mục bạn vừa tải 
2. nếu bạn thấy .bat hoặc .vbs thì bạn nhấn 1 trong 2 :)
3. enjoy :)
SO = NÊN 
bạn không cài được cilent mods thì bạn hãy làm theo mình:
1. mở CMD :"Win + R" gõ ~cmd~
2. gõ ~cd [ tệp lưu cilent ]~  | Vd : cd /d "%USERPROFILE%\Downloads"
3. gõ tiếp dir *.jar ( liệt kê các .jar ) 
4. gõ tiếp trong CMD : java -jar "ten-file-installer.jar" | VD :  java -jar "forge-1.20.1-installer.jar"
